How to size a diesel generator for your site

Most sizing mistakes come from two things: forgetting motor starting current, and buying exactly the running load with no headroom. This is the method we use when a buyer sends us a load list.

1. List the loads and add the running kW

Write down every load that can run at the same time, with its rated power in kW. Lighting, sockets and electronics are simple. Motors (pumps, compressors, crushers, conveyors, air conditioning) need a second look in step 2.

2. Check the largest motor start

A motor started direct-on-line draws about 6 to 7 times its running current for a few seconds. The generator must carry that without the voltage collapsing. As a rule of thumb:

  • Direct-on-line start: allow roughly 3 kVA of generator per kW of the largest motor.
  • Star-delta start: about 2 kVA per kW.
  • Soft starter or VFD: about 1.2 to 1.5 kVA per kW.

Start the largest motor first and the others one by one. If several large motors may start together, add them.

3. Convert kW to kVA

Generators are rated in kVA at power factor 0.8. So kVA = kW ÷ 0.8. A 400 kW running load needs at least 500 kVA.

4. Leave 20–25% headroom

Diesel engines live longest at 50–80% of their prime rating. Running a set continuously near 100% shortens its life; running it below 30% causes wet stacking. Size so that the normal load sits around 70–80%.

5. Prime or standby?

If the set is your main source of power, size against the prime rating. If it only runs during grid outages, the standby rating applies. See prime vs standby.

Worked example

A small mine site has 250 kW of running load, and its largest load is a 75 kW crusher motor with a star-delta starter.

  • Running load: 250 kW ÷ 0.8 = 313 kVA.
  • Motor start check: 75 kW × 2 = 150 kVA extra during starting, so about 460 kVA momentarily.
  • With 20% headroom on the running load: about 375 kVA.
  • Choose a 500 kVA (400 kW prime) set, which covers both the start and the running load with margin.
